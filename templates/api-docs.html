🚀 Quick Start

Include the SDK

<script src="https://gen.apilageai.lk/static/apilage-sdk.js"></script>

Basic Usage

// Initialize client with authentication
// Get your credentials from your admin panel
const client = new ApilageAI({
    baseUrl: 'http://localhost:5002',
    authCode: 'YOUR_AUTH_CODE_HERE',
    apiKey: 'YOUR_API_KEY_HERE'
});

// Generate a video and wait for completion
const video = await client.generateAndWait('Explain the Pythagorean theorem', {
    level: 'basic',
    onProgress: (status) => {
        console.log(`Status: ${status.status} - ${status.progress}`);
    }
});

console.log('Video URL:', video.fullUrl);

// Or use step-by-step approach
const job = await client.generate('Explain photosynthesis');
console.log('Job ID:', job.id);

// Check status later
await job.refresh();
if (job.isComplete()) {
    console.log('Video:', job.fullUrl);
}

🔐 Authentication

All API endpoints require authentication using two custom headers. This ensures only authorized users can access and use your API.

Required Headers

HeaderDescriptionExample
X-Auth-CodeYour unique authorization codeYOUR_AUTH_CODE_HERE
X-API-KeyYour unique API keyYOUR_API_KEY_HERE

Include Headers in Every Request

All requests to protected endpoints must include both headers. Without valid credentials, you'll receive a 401 Unauthorized response.

cURL
JavaScript
Python
curl -X POST http://localhost:5002/api/generate \
  -H "X-Auth-Code: YOUR_AUTH_CODE_HERE" \

    "X-Auth-Code": "Your authorization code",

Security Tips

  • Keep credentials private: Never share your Auth Code or API Key
  • Use environment variables: Store credentials in .env files, not hardcoded
  • Use HTTPS: Always use HTTPS in production to protect credentials in transit
  • Rotate periodically: Consider rotating credentials if you suspect compromise
  • Never expose in logs: Be careful not to log or expose credentials

📦 SDK Reference

Constructor Options

const client = new ApilageAI({
    baseUrl: 'https://gen.apilageai.lk',      // API base URL
    authCode: 'your-auth-code',                // Required: Authorization code
    apiKey: 'your-api-key',                    // Required: API key
    pollInterval: 3000,                        // Status polling interval (ms)

Methods

MethodDescription
generate(topic, options)Submit video request, returns Job
generateAndWait(topic, options)Generate and wait for completion
getStatus(jobId)Get job status
getVideo(jobId)Get video details
cancelJob(jobId)Cancel pending job
getQueue()Get queue status

Job Object

const job = await client.generate('Topic');

job.id              // Job ID
job.status          // 'pending' | 'processing' | 'completed' | 'failed'
job.progress        // Current progress message
job.queuePosition   // Position in queue (if pending)
job.videoUrl        // Video URL (if completed)
job.fullUrl         // Full video URL with domain
job.error           // Error message (if failed)

await job.refresh();              // Update status from server
await job.waitForCompletion();    // Wait until done
await job.cancel();               // Cancel if pending
