🚀 Quick Start

Include the SDK

<script src="https://nova.apilageai.lk/static/apilage-sdk.js"></script>

Basic Usage

// Initialize client with authentication
const client = new ApilageAI({
    baseUrl: 'https://nova.apilageai.lk',
    authCode: 'YOUR_AUTH_CODE',  // Request from admin
    apiKey: 'YOUR_API_KEY'        // Request from admin
});

// Generate a video and wait for completion
const video = await client.generateAndWait('Explain the Pythagorean theorem', {
    onProgress: (status) => {
        console.log(`Status: ${status.status} - ${status.progress}`);
    }
});

console.log('Video URL:', video.fullUrl);

// Or use step-by-step approach
const job = await client.generate('Explain photosynthesis');
console.log('Job ID:', job.id);

// Check status later
await job.refresh();
if (job.isComplete()) {
    console.log('Video:', job.fullUrl);
}

📡 API Endpoints

POST /api/generate

Submit a new video generation request. Returns a job ID for tracking.

Request Body

ParameterTypeRequiredDescription
topicstringYesTopic to explain (3-500 chars)
cURL
JavaScript
Python
curl -X POST https://nova.apilageai.lk/api/generate \
  -H "Content-Type: application/json" \
  -H "X-Auth-Code: YOUR_AUTH_CODE" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{"topic": "Explain the water cycle"}'
// Authentication is handled automatically by the SDK
const client = new ApilageAI({
    authCode: 'YOUR_AUTH_CODE',
    apiKey: 'YOUR_API_KEY'
});
const job = await client.generate('Explain the water cycle');
console.log('Job ID:', job.id);
import requests

headers = {
    'Content-Type': 'application/json',
    'X-Auth-Code': 'YOUR_AUTH_CODE',
    'X-API-Key': 'YOUR_API_KEY'

response = requests.post('https://nova.apilageai.lk/api/generate',

GET /api/status/{job_id}

Check the status of a video generation job.

📦 SDK Reference

Constructor Options

const client = new ApilageAI({
    baseUrl: 'https://nova.apilageai.lk',  // API base URL
    authCode: 'YOUR_AUTH_CODE',             // Your authentication code
    apiKey: 'YOUR_API_KEY',                 // Your API key
    pollInterval: 3000,                     // Status polling interval (ms)
    timeout: 30000                          // Request timeout (ms)
});

Methods

MethodDescription
generate(topic, options)Submit video request, returns Job
generateAndWait(topic, options)Generate and wait for completion
getStatus(jobId)Get job status
getVideo(jobId)Get video details
cancelJob(jobId)Cancel pending job
getQueue()Get queue status
getVideos(options)List all videos
health()Health check

Job Object

const job = await client.generate('Topic');

job.id              // Job ID
job.status          // 'pending' | 'processing' | 'completed' | 'failed'
job.progress        // Current progress message
job.queuePosition   // Position in queue (if pending)
job.videoUrl        // Video URL (if completed)
job.fullUrl         // Full video URL with domain
job.error           // Error message (if failed)

await job.refresh();              // Update status from server
await job.waitForCompletion();    // Wait until done
await job.cancel();               // Cancel if pending
